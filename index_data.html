📋 Конструктор СОУТ реквизиты + рабочие места

📖 Мини-инструкция — как пользоваться конструктором

▾
  1. Заполните карточку организации. Введите ИНН или название и нажмите «Загрузить» — реквизиты подтянутся автоматически.
  2. Укажите адреса проведения замеров. Они заполняются автоматически из подразделений.
  3. Заполните комиссию по СОУТ. Минимум 3 человека, нечётное количество.
  4. Добавляйте рабочие места. Кнопка «➕ Подразделение» внизу страницы; внутри — «➕ Рабочее место».
  5. В карте рабочего места: должность (код ОК-016 подтянется из ОКПДТР), сменность, смена, класс УТ, рабочие зоны, оборудование, материалы, описание.
  6. Сотрудники. ФИО и СНИЛС. Численность подставляется автоматически — кнопка ↺ Авто. При отказе от ФИО/СНИЛС — ручной ввод количества.
  7. Гарантии и компенсации. Если гарантий нет — отметьте «Гарантии отсутствуют». Медосмотры — «да/нет»; при «да» появится блок 29Н. Основание досрочной пенсии показывается только при выборе «да».
  8. Нумерация. Если указан № по предыдущей СОУТ — он становится номером рабочего места. Иначе — авто.
  9. Экспорт. «Excel» — два листа. «Word» — карточка + сводная + итоги. «📄 Скачать приказ» — приказ о создании комиссии по СОУТ. «📥 Импорт перечня» — добавление данных из файла (Excel, CSV, JSON, текст).
Кнопки:
✕ Закрыть — закрыть окно / удалить элемент (рабочее место, подразделение, сотрудника, оборудование, зону, адрес, члена комиссии)
📋 Список — открыть справочник для выбора значения (должности, оборудование, материалы, зоны, 29Н, ФЗ-400, ОКПДТР)
➕ Добавить — добавить новую запись (подразделение, рабочее место, оборудование, пункты)

Политика конфиденциальности

Настоящая Политика конфиденциальности описывает порядок обработки и защиты персональных данных, которые передаются через настоящий сервис.

1. Общие положения

Обработка персональных данных осуществляется в соответствии с ФЗ от 27.07.2006 № 152-ФЗ «О персональных данных».

2. Какие данные обрабатываются

  • Данные организации (наименование, ИНН, КПП, ОГРН, адреса);
  • ФИО, СНИЛС сотрудников;
  • Сведения о рабочих местах, условиях труда, гарантиях и компенсациях.

3. Цели обработки

Данные обрабатываются исключительно для целей проведения специальной оценки условий труда (СОУТ) и подготовки документации.

4. Передача третьим лицам

Все данные обрабатываются в соответствии с договорами и не подлежат распространению третьим лицам, за исключением случаев, прямо предусмотренных законодательством РФ.

5. Защита данных

Принимаются необходимые организационные и технические меры для защиты персональных данных.
